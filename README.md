# FEM data generation

This folder contains the seven Python scripts used to generate the meshes
and hydrodynamic data.
## Files

- `FB2_parametric_mesh_generator.py`: initial fitting-case meshes.
- `FB2_parametric_solver.py`: radiation and diffraction calculations.
- `FB2_validation_mesh_generator.py`: initial 12 verification-case meshes.
- `FB2_validation_solver.py`: verification calculations using the same solver.
- `FB2_atlas_additional_mesh_generator.py`: meshes for TN33–TN37 and VN13–VN24.
- `FB2_atlas_additional_solver.py`: calculations for these additional cases.
- `FB2_parametric_solver_Addedmass.py`: infinite-frequency added mass.

Keep the files together: several scripts import functions from the others.
Geometry definitions and numerical settings are in the scripts.

## Environment

Use Linux or WSL with a compatible DOLFINx installation, complex-valued
PETSc/petsc4py, mpi4py, UFL, Gmsh, NumPy and Matplotlib. A real-valued PETSc
installation is not sufficient for the frequency-domain solver. The scripts
use `dolfinx.io.gmsh`; the installed DOLFINx version must provide that API.

## Run order

Run these commands from this folder in the configured FEM environment.
First generate the meshes:

```bash
python FB2_parametric_mesh_generator.py
python FB2_validation_mesh_generator.py
python FB2_atlas_additional_mesh_generator.py
```

For a first individual calculation:

```bash
python FB2_parametric_solver.py --case TN01 --points 100
python FB2_validation_solver.py --case VN01 --points 100
```

For the full database:

```bash
python FB2_parametric_solver.py --points 100
python FB2_validation_solver.py --points 100
python FB2_atlas_additional_solver.py --points 100
```

The additional launcher explicitly covers TN33–TN37 and VN13–VN24.
Existing results are skipped unless `--overwrite` is supplied. The default
launchers use four independent case workers; run them with ordinary Python,
not `mpirun`. The original scripts may also generate benchmark cases.

After generating the meshes, obtain the infinite-frequency added mass for
the fitting geometries with:

```bash
python FB2_parametric_solver_Addedmass.py --group TN
```

The scripts create case folders, mesh files, case metadata and NPZ results
beside the scripts. The finite-period results contain added mass, radiation
damping and complex excitation loads. Any diagnostic plots generated by the
solver are separate from the numerical results.
